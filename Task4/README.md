# Задание 4. Защита доступа к кластеру Kubernetes

## Роли и их полномочия при работе с Kubernetes

| Роль     | Права роли                                                                                                                                                                | Группы пользователей       |
| :------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------- |
| dev_admin    | Полный контроль над ключевыми компонентами системы, управление правами, RBAC                                         | Администраторы кластера |
| dev_ops      | Расширенные права для управления приложениями (развертывание, управление сервисами и конфигами) | DevOps инженеры                       |
| viewer       | Просмотр информации о подах, сервисах, логов, мониторинг состояния кластера                                        | Менеджеры \ Разработчики |
| secret_admin | Управление секретами                                                                                                                                            | Специалист ИБ                     |

## Скрипты, чтобы создать роли

kubectl apply -f roles.yaml

## Cкрипт для создания пользователей + связывание с ролями

./create-users.sh
